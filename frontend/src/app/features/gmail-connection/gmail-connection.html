How it works

01Authorize account

Google OAuth grants read-only access to your Gmail inbox.

02Initial sync

The backend imports and classifies the latest candidate messages.

03Push updates

Pub/Sub signals mailbox changes; the backend uses the History API for incremental sync.

04Human review

Every AI-suggested response stays under your control — nothing is sent automatically.

Security note: Only gmail.readonly scope is requested. Drafts are stored locally — no email is ever sent by this application. Real-time push delivery requires an HTTPS-accessible backend endpoint (e.g. via ngrok). See docs/setup-google-cloud.md for setup details.
